## 先分清逻辑结构与存储结构

线性表表达元素有前后次序，这是逻辑关系。顺序表用连续数组存储，链表用结点和指针存储，这是物理实现。同一份通讯录可以用两种结构实现；姓名相同、显示结果相同，并不意味着插删算法相同。

栈和队列都是限制操作端的线性结构。栈后进先出，队列先进先出，不是“栈只能数组、队列只能链表”。顺序栈、链栈、循环队列和链队列都能实现相应抽象操作。

## 复杂度要说明操作条件

O(1) 表示操作次数不随 n 增长，不等于只执行一条指令。O(n) 常见于完整扫描；循环 i 每次乘 2、直到 n 的次数是 O(log n)；内层从 0 到 i 的双循环次数为 n(n-1)/2，属于 O(n²)。并列两个长度 n 的循环仍是 O(n)，不是 O(n²)。

顺序表按下标取值 O(1)，按姓名查找 O(n)。链表已知前驱后改链接 O(1)，按姓名找到要删的人并删除整体 O(n)。你现有单链表尾插每次从头找尾，连续插入 n 人总计 O(n²)；固定展示十个人只是样例，分析时把人数看成可增长参数。

## size、capacity、下标和位序

size 是当前有效元素数，capacity 是可容纳数量，有效下标为 0 到 size-1。插入可选下标 0 到 size，删除只能选 0 到 size-1。教材说“第 i 个元素”经常采用从 1 开始的位序，需要转换到下标 i-1，答题时先看函数约定。

## 读懂课堂的指针写法

`SL s1` 是结构体对象；`&s1` 取它的地址；形参 `SL* ps` 接收地址；`ps->size` 等价于 `(*ps).size`。改变 ps->size 修改原对象，单纯把局部 ps 赋给别的地址不会替调用者修改指针变量。

`typedef LNode* LinkStack` 让 LinkStack 成为指针类型，`LinkStack* S` 实际是 LNode**。你链栈的 InitStack 通过 *S 改变调用者的栈指针，因此需要二级指针。C++ 也可用引用表达类似意图，但考场应遵守课上接口。

## 内存配对与字符串

malloc 与 free 配对，new 与 delete 配对，new[] 与 delete[] 配对，不能混用。当前通讯录结点只含字符数组和指针，采用 C 风格分配；若以后改成 std::string 等需要构造析构的对象，不应继续把 malloc 当作 new 的替代。

`strcmp(a,b)==0` 才表示 C 字符串内容相等；a==b 比较指针通常不是比较名字。char name[20] 的容量按字节计，UTF-8 中文并不是一个字一个字节。演示固定短字符串并不意味着任意长输入都安全。

## 自测

1. 两个顺序执行的 n 次循环：O(n)。
2. 从头寻找第 i 个链结点：O(i)，最坏 O(n)。
3. 长度为 n 的顺序表有效删除位置：0…n-1。
4. free 后再读 p->next：无效访问；要先保存 next。
5. 将函数形参写成对象按值传递，修改内部 size：不会改变调用者原对象；使用指针或引用才能达到原课堂操作的效果。
